# Barbearia Project

A web-based management system designed to streamline barbershop operations. This project was developed by me to gain hands-on experience with the full application lifecycle, from development to deployment.

## Key Features
- **Appointment Management:** Book, edit, and track customer services.
- **Service Dashboard:** View daily, weekly, or monthly logs.
 
------

## Tech Stack
**Frontend:** Node.js/vite/JavaScript.

**Backend:**  Python/FastApi.

**Database:** PostgreSQL.
