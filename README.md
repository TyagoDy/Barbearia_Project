# Barbearia Project 💈

A full-stack management system designed to automate barbershop operations, appointment scheduling, and customer logging. This project showcases a decoupled architecture utilizing a Python backend API and a responsive frontend interface.

---

### 🚀 Key Features

* **Appointment Engine:** Seamless workflow to book, update, and track customer service slots.
* **Service Dashboard:** Structured logging viewpoints sorted by daily, weekly, or monthly intervals.
* **Containerized Environment:** Fully configured via Docker for predictable development environments.
* **Production-Ready Specs:** Prepared for automated deployments using Render blueprint configurations.

---

### 🛠️ Technical Architecture & Stack

* **Backend API:** FastAPI (Python) - High performance, asynchronous routing, and strict data validation using Pydantic.
* **Frontend UI:** JavaScript, HTML5, CSS3 - Responsive interface built for seamless client interaction.
* **Database Layer:** PostgreSQL - Relational schema designed for efficient transactional persistence.
* **DevOps & Infrastructure:** Docker, Docker Compose, Render Blueprint (`render.yaml`)
